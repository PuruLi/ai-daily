RT 區塊先生 🐡 ⚠️ (rock #58)
Open Design 是由 @tuturetom（http://Nexu.io 聯合創辦人兼 CEO）在 2026 年 4 月正式開源的專案，被定位為 Anthropic Claude Design 的本地優先、高保真開源替代品。

它在短短 72 小時內 完成 18,700+ 行程式碼，達到 超過 95% 的還原度，完整逆向並濃縮了 Claude Design 最先進的設計工作流程、最精美的模板與體驗。

專案採用 Apache 2.0 完全開源，GitHub 地址：
🔗 https://github.com/nexu-io/open-design
主要功能亮點
• 支援 30+ 個可組合的頂級設計 Skills（包含 Twitter 上廣為流傳的精緻模板）
• 內建 71+ 套品牌級設計系統（Linear、Stripe、Apple 等業界頂尖系統，可直接一鍵復刻）
• 相容 16+ 個 Code Agent（Claude Code、Cursor、Codex、Gemini、OpenClaw、OpenCode 等）
• 本地 Daemon 模式：自動偵測你電腦 PATH 上的所有 AI 程式碼 Agent，一鍵復用你已付費的大額會員額度
• 本地檔案系統映射 + 草圖轉原型：可直接讀取本地專案檔案、預覽任意檔案，還能把手繪草圖瞬間變成高保真原型
• 完整 Agent 引導機制：內建互動表單、視覺風格選擇器、TODO 自省系統，確保輸出的 Web/Mobile 原型、Slides 都能達到「可直接上線生產」的品質，並支援持續追問修改
• 一鍵匯出與預覽：支援 HTML、PDF、PPTX、MP4 等格式，內建沙盒即時預覽，可直接演示、分享

今天发布的Codex Chrome插件用上了，有几个坑：

1. 更新Codex，第三方API模式不支装插件，切为官方订阅登录。

2. Codex Chrome插件安装挑节点，比如香港地区不支持，有些节点会打不开页面。

3. 建议把Chrome设置为默认浏览器，有步骤会引导跳默认浏览器。

4. 如果死活连不上插件，可以重启电脑试试。

简单安装流程：

升级Codex -&gt; 打开设置 -&gt; 电脑控制（Computer Use）-&gt; Google Chrome，安装浏览器插件

必须在Codex 对话中用 @ Chrome 调用。

Terminal 版 Codex虽然能调用Chrome skill，但找不到node_repl，有点坑。
