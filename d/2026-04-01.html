Agent harnesses are too restrictive.

That's because they're still designed as code.

What if the harness itself were written in natural language and interpreted by an LLM at runtime?

This research explores the idea.

The work introduces Natural-Language Agent Harnesses (NLAHs), a structured natural-language representation that externalizes harness logic as a portable, executable artifact.

Instead of scattering control flow across controller code, framework defaults, and tool adapters, NLAHs make contracts, roles, stage structure, state semantics, and failure taxonomies explicit and editable.

An Intelligent Harness Runtime (IHR) places an LLM inside the runtime loop to interpret and execute these harnesses directly.

Why does it matter?

Harness design is increasingly decisive for agent performance, but it's buried in code that's hard to transfer, compare, or ablate.

NLAHs make the orchestration layer a first-class scientific object.

The practical implication: harnesses become portable across runtimes, composable across tasks, and directly inspectable by humans and models alike.

先制造焦虑：你不学AI就要被淘汰，不做副业就要被裁员，不掌握这套方法论就永远没有出路。

然后提供解药：10节课，3999，限时优惠，今天下单立减1000。

但真正被出售的，其实是付款那一刻的安心感。我买了，我在行动，我就安全了。

所以你明白为什么这些课的内容普遍是废话了。

因为内容真的不重要。

不过内容必须看起来有价值，但也不能真的有价值。真的有价值意味着你学会了，不需要再买下一门了。

这个模式最精妙的地方是：被割过的人，不但不会揭穿这件事，反而会主动加入进来为这个谎言站台，继续割。因为他们没有办法承认自己被骗了。

你想想，花了三千块学了一套"月入过万自媒体方法论"，学完发现没用。怎么办？

承认方法论是假的吗？我被骗了，我损失了三千块。

不，这太难了。

接受这个结论意味着：我是傻瓜，我被人耍了，我的钱打了水漂。大脑天然排斥这个结论，会自动去找另一个解释。

所以，最让人舒服的解释是，方法是对的，是我自己还没做好。

我执行力不够。我没有坚持。我悟性太低。我需要再学一门配套的课。

于是这个人开始自我说服，然后开始传播这套东西。他真诚地告诉身边的朋友：这套方法很好，这个老师说的很对，就是要坚持，你也来学一学。

他其实也不是在骗人。因为他自己真的也信了。

某种程度上，这和传销的运作原理是一样的。

囤了一批货发现被骗，不愿承认，开始拉下线稀释损失，拉下线的时候，自己也慢慢信了。

买了课发现没用，不承认，于是自己开始讲故事，我用豆包搭自动化工作流吗，副业月入8万，我用6个龙虾员工24小时在线，月入10万。

视频拍起来，课也卖起来。总有人成为韭菜，也总有韭菜成为镰刀。

被割的人变成了割人的人。

下一批被割的人，又会经历同样的循环。

这个生态永远跟着风口走。

区块链来了，卖区块链课。元宇宙来了，卖元宇宙课。ChatGPT来了，卖AI应用课。龙虾刚火，课已经卖了几百万。

有位自称清华博士的李老师，靠一套AI课年收入过千万，被网友并列奥特曼，称为华人AI双雄。

你可能会想，那些学员为什么不去B站搜一下，明明都是免费的？

因为这不是信息检索能力的问题。是个焦虑管理的问题。

人在焦虑的时候，不需要最好的信息，需要的是确定感。

付了钱，进了群，有老师答疑。

这一套仪式感，给了焦虑的大脑一个"我在行动了"的信号。

这个割韭菜系统存在这么多年，从成功学到知识付费，从励志课到AI副业课，风口换了一茬又一茬，但从来没有彻底消失过。

不是割的人手段有多高明，是因为焦虑永远不会消失。

只要有人害怕落后，就有人需要一个我在努力的证明。

因为镰刀不需要进化，韭菜会自己长回来。
